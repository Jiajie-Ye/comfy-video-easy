# Contributing

Use Python 3.11, install `requirements-dev.txt`, and run `python -m unittest test_modern test_engine -v` with `QT_QPA_PLATFORM=offscreen`. Keep Chinese and English labels in sync. Do not include personal server addresses, credentials, workflow exports, model inventories, media or task records in issues and pull requests. Use synthetic test data. Changes to sampling must include relevant offline tests and describe any live-server validation separately.
