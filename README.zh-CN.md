# Comfy Video Easy · AI 视频助手

[English](README.md) | **简体中文**

项目主旨：帮助从未接触过 AI 视频制作的新手，以及年纪较大的使用者快速入门。通过清晰的中文操作、素材预览和简单的步骤，让大家无需先学习 ComfyUI 节点编辑，就能开始制作自己的视频。服务器和模型仍需由熟悉环境的人提前配置。

简洁的 Windows 桌面客户端，将 ComfyUI MiniMax H3 视频工作流整理成易用的表单。支持中文 / English、参考素材、两阶段采样及本地末帧提取。

> 本项目适配特定 MiniMax H3 参考视频工作流，不是任意 ComfyUI 工作流的通用前端。模型和自定义节点需要用户自行在服务器安装；仓库不包含模型权重、私人服务器地址、素材或生成记录。

## 功能

- 图片、音频、视频参考素材；图片缩略图和双击预览。
- Prompt、画面比例、1–15 秒整数时长；鼠标滚轮、箭头和键盘输入。
- 一采 / 二采、随机或固定种子、分辨率和采样参数。
- 任务记录、下载、恢复查询、载入参数和继续二采。
- 界面内视频预览、播放进度控制、可选系统播放器，以及 FFmpeg 提取最后一帧。
- 浅色圆角界面；右上角切换中英文，快捷键 Alt+L。

## 环境与启动

目标环境：Windows 10 / 11 x64、Python 3.11。已在开发电脑及 GitHub Windows 运行环境验证，未覆盖所有 Windows 版本。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python modern_app.py
```

将 FFmpeg 和 FFprobe 加入 PATH，供参考视频检测和末帧提取使用。首次启动后进入 **高级设置 / Settings**，填写自己的 ComfyUI URL。默认是 `http://127.0.0.1:8188`，也支持可访问的局域网或 Tailscale 地址。

客户端需要访问 `/system_stats`、`/object_info`、`/upload/image`、`/prompt`、`/queue`、`/history`、`/view`。目前没有登录或 API token 输入界面；它适用于你信任的本地或私有网络连接。不要将未设访问控制的 ComfyUI 直接开放到公网。

## 配置服务器

编辑 `profile.json`，让模型、CLIP、VAE、LoRA 文件名与服务器一致。该文件是公开示例配置，不包含模型本身。修改后重启；打包版本需重新构建。

除 ComfyUI 核心采样节点外，此工作流使用：

- `MiniMaxH3ReferenceToVideo` 及支持 MiniMax 的模型加载器。
- `ResolutionSelector`。
- `LayerUtility: ImageScaleByAspectRatio V2`。
- `VHS_LoadVideo`、`VHS_VideoCombine`。
- `ImageResizeKJv2`。
- `PT_H3ConcatAVLatent`。

服务器节点版本必须兼容 `engine.py` 中的输入定义。点击“检查连接”会检查模型文件名和节点是否存在；运行时还会校验 API 图。模型和节点按各自许可证获取、使用。

## 使用

固定选项参数需点击展开下拉列表，滚轮经过不会再改值；数字输入保持原样。高级设置的“恢复默认参数”可重置生成选项，同时保留服务器地址、Prompt 和参考素材。

参考图片区新增顶部“提取末帧”按钮：点击后可选择“从本地文件选择”或“从已完成任务选择”。后者直接列出已完成且已下载的视频，显示日期、名称和描述并支持搜索，不用查找文件夹。选择视频并点击“提取并添加”后，末帧会保存到本地，自动加入参考图片并显示缩略图和 Picture 编号。仍遵循最多 9 张图片的限制。

1. 配置服务器，检查连接。
2. 添加素材，按 `<Picture 1>`、`<Audio 1>`、`<Video 1>` 引用。排序会改变编号。
3. 写入画面描述与对白，设置时长、比例和采样参数，开始生成。
4. 在“我的任务”选择结果；右侧可播放或提取末帧。
5. 满意后选择“用这条做二采”，复用保存的一采参数和种子。

图片最多 9 张，音频和视频各 3 段；参考视频仍要求 2–15 秒。输出时长按模型的 `17k+5` 帧网格、24 fps 对齐，可能略长于设置值。1–4 秒短于模型标注的常用训练范围，生成质量未验证。二采操作会重建一采及二采 API 图，并非读取先前任务的内部 latent 缓存。

任务、设置和素材路径保存在下文说明的固定工作目录中，升级时保留该目录。它可能含私人 Prompt、服务器地址和素材路径，不应提交到公开仓库。

每张参考图片左侧有 **@** 按钮，点击即可在描述框光标处插入对应的 `<Picture N>`。重新排序后按钮按新编号插入，已写入的文本不会自动改号。

点击图片旁的 **设为首帧**，将该图作为第 0 帧引导；一次仅选一张，再点 **✓ 首帧** 可取消。排序时跟随文件，删除该图片则清除选择，参考编号保持原顺序。一采、二采分别通过 `MiniMaxH3AddGuide` 按各自分辨率加入引导。这是模型条件控制，不是后期替换第一帧，也不保证逐像素一致；不同画面比例会居中裁剪。提示词增强同步读取首帧编号，服务器须具备此节点。


剪辑预览进度条按整条时间轴计时，跨片段拖动会换算裁剪入点；片段宽度与时长成比例。拖动时片段跟随鼠标并显示插入线。切换视频源时保留上一幅有效画面，下一段解码完成后更新，避免黑色闪屏；加载时仍可能短暂停留。导出渲染保持原样。

## 剧本提示词增强

点击描述框下方“剧本提示词增强”，首次填写接口格式、URL、API KEY 和准确模型名；以后直接使用保存的配置。“增强设置”中可随时修改。支持 OpenAI Compatible、OpenAI Responses、Anthropic、Google Gemini，以及使用 Bedrock Bearer API Key 的 Amazon Bedrock Converse（不支持 AWS Access Key 签名认证）。

“参考格式文本”页支持直接粘贴或导入 TXT / Markdown。内置通用格式整理素材映射、连续性、时长、分镜、声音和限制条件，不套用示例剧情。只发送剧情、参考格式、时长和素材数量，不发送媒体文件或本地路径。结果先预览、可编辑，再应用；Ctrl+Z 可撤销，原文和结果另存在本地 `prompt_history` 中。

增强以点击时界面设置的生成时长（1–15 秒）为准，不需要在剧情中另写时长；原文或参考示例中的时长不一致时，也以界面设置为准。模型会收到从 0 秒连续安排到目标时长、按时长调整分镜和节奏的要求。预览标题显示本次时长；等待期间修改时长，应用结果前会提醒确认。

API KEY 使用 Windows 当前账号 DPAPI 加密保存，不写入任务记录或日志；换电脑或账号后需重新填写。兼容 Chat 接口由服务商决定输出上限，其他接口提供输出长度设置。各服务商模型支持情况不同，协议测试使用模拟返回；真实调用需要填写自己的接口配置。

## 人物/场景图像生成

在图片卡片点击“人物/场景图像生成”，打开独立窗口填写描述，可从本地或当前视频素材选择参考图片。首次生成会要求填写图像接口格式、URL、API KEY 和准确的图像模型名称，之后沿用保存的配置。右侧预览生成结果，可放大查看，满意后点击“加入参考图片”；不会自动插入，也不会改写视频剧本或改变已有首帧选择。

支持 OpenAI Images 兼容接口（纯文本使用 `/images/generations`，带参考图使用 multipart `/images/edits`）及 Gemini `generateContent` 图像输出。这不是任意 Chat Completions 接口，所选模型须支持图像生成，带参考图还须支持图像输入。请求格式参考 [OpenAI 官方图像文档](https://developers.openai.com/api/docs/guides/image-generation)和 [Gemini 接口文档](https://ai.google.dev/api/generate-content)。每次请求一张图，若接口返回多个结果可选择。最多 9 张参考图，单张不超过 2500 万像素，转成 PNG 后总计不超过 15 MB。

点击生成时会把描述和所选参考图内容发送到配置的服务商。图像密钥以 Windows DPAPI 加密，独立保存在 `image_settings.json`；与提示词增强互不覆盖。生成图片留在固定工作目录的 `generated_images` 中，窗口显示最近 20 张，并记住描述草稿。切换工作目录时会复制设置、草稿和生成结果。失败不自动重试。协议与界面测试使用模拟图片，真实服务商兼容性需用自己的图像接口配置验证。

## 固定工作目录与旧任务

新版通过 `%LOCALAPPDATA%/ComfyVideoEasy/workspace.json` 记住同一 Windows 用户的工作目录。全新安装默认使用用户文档下的 `AI视频助手工作区`；没有目录记录时，若 EXE 旁存在旧“我的视频数据”，会优先接入。显式 `--data-dir` 参数不修改固定目录记录。

在高级设置里可选择固定工作目录和独立的视频保存目录，并恢复工作目录下默认的“视频作品”目录。换保存目录会保留旧任务来源，不再让历史列表变空。“我的任务”或设置里的“导入旧任务”可选择旧程序文件夹、旧数据文件夹或包含 task.json 的视频作品目录；复制过的任务文件夹会尝试使用同目录下的视频。

切换工作目录会复制配置、草稿和辅助文件，已有目标配置不会覆盖。旧视频保留原处并继续显示，因此不要删除旧视频所在目录。升级只需替换 EXE，保留固定工作目录。配置、剧情、加密密钥和媒体不提交到 GitHub。

## 简易视频剪辑

左侧打开“视频剪辑”，可从已完成任务或本地一次添加多个视频。点击时间轴选择片段和定位，左右拖动片段调整顺序；设置入点、出点后应用裁剪，也可以在播放头位置分割、删除不需要的片段，并使用撤销。草稿自动保存到数据文件夹下的 `editing_project.json`，不修改原视频。

可以预览裁剪后的拼接顺序，导出横屏或竖屏的 720p / 1080p MP4。不同宽高比使用留边适配；输出统一为 30 fps、H.264 视频和 AAC 音频，无声片段自动补静音。处理支持取消；只有导出成功才会替换已有输出文件。

“自动识别字幕”采用本地 Whisper.cpp v1.8.2 CPU 组件和多语言 base 模型，首次提示从官方 GitHub / Hugging Face 下载约 160 MB，校验 SHA-256 后使用。安装完成后无需上传媒体。识别可能有错字，请在“编辑字幕”中校对；也支持导入 SRT 或手动填写字幕。导出可将字幕烧录进画面，或保存为可开关的字幕轨。裁剪、分割、重新排序后会清除已有字幕以防错位，建议先剪辑再识别。

这是单轨简易剪辑，不包含多轨叠加、转场和复杂混音。预览使用 Windows 多媒体组件，部分不支持的编码可能需要转换。“我的任务”现在切换任务或结果文件时，会自动显示对应视频的暂停预览。

## 构建 EXE

```powershell
pip install -r requirements-dev.txt
$env:CVE_FFMPEG_DIR = 'C:\tools\ffmpeg\bin'
python build_exe.py
```

目录须包含 `ffmpeg.exe`、`ffprobe.exe` 及其依赖 DLL。输出为 `dist/AI视频助手.exe`。构建脚本不会下载第三方二进制；分发时需附带所选 FFmpeg 构建及 Qt/PyQt 等组件要求的许可证和源码说明。

## 测试

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
python -m unittest test_modern test_engine test_editing test_enhancer test_workspaces test_images -v
```

离线测试使用最小、去除服务器枚举的节点 fixture，不代表真实服务器所有版本的兼容性，也不会提交 GPU 任务。

```powershell
python modern_app.py --self-test test_artifacts/self_test
```

自检需要 FFmpeg / FFprobe。可另加 `--check-server` 检查默认本地服务器；普通自检不连接服务器。
